# Data Availability

Input and derived data required to reproduce the reported analyses are included in this repository package.

Included inputs:

- Sonde hydrography inputs: `analysis/hydrography/pie_temp_sal_sonde.csv`, `analysis/hydrography/High Tide Values.csv`
- Burrow survey inputs: `analysis/burrow/burrow_density.csv`, `analysis/burrow/PIE Fiddler Surveys_Master_V12.xlsx`
- Food-web mixing inputs and outputs: files in `analysis/plankton/`

Included derived outputs:

- Summary tables: `results/`
- Figure files: `figures/`

Long-term isotope dataset citation retained in manuscript references (Deegan & PIE LTER, Environmental Data Initiative; doi:10.6073/pasta/78895624039aaa0e75c6d71970fd7fb4).
