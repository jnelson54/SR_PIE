# Code Availability

All analysis scripts used for the manuscript are provided in this repository under `analysis/`.

Primary scripts:

- Hydrography (Fig. 1): `analysis/hydrography/analysis_pie_temp_sal_sonde.R`
- Burrow density (Fig. 2 support): `analysis/burrow/burrow_density_analysis.R`
- Plankton trends (Fig. 3): `analysis/plankton/fig_plankton_trends_nyt_with_fiddler.R`
- MixSIAR model workflow: `analysis/plankton/mixsiar_gcb_fids.R`

The plotting theme used across analyses is in `analysis/common/theme_nyt.R`.
