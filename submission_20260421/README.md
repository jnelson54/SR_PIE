# Submission assets, 2026-04-21

This folder gathers figure files and source-data files with names aligned to the current manuscript numbering. Original analysis output filenames are left unchanged elsewhere in the repository.

Figure PNGs were extracted from the current `GCB_Fiddler_Niche_submission_ready_2026_4_21.docx` manuscript file.

Note (archive v1.1.0): `figures/Fig1_map.png` has been removed. That map used a commercial imagery basemap. The current Fig. 1, drawn on public-domain USGS base maps, is `manuscript_figures/figures/Fig1_study_area_map.png`.

## Figure numbering

- Fig1: study area and sampling locations.
- Fig2: hydrography anomalies and trends.
- Fig3: mud fiddler burrow density and occupancy.
- Fig4: plankton support and mud fiddler MixSIAR estimates.
- SuppFig1: Parker River discharge.
