# Code Availability

All analysis scripts used to generate the packaged figures and derived tables are included in this repository under `analysis/`.

Primary scripts:

- Study area map: `analysis/study_area/make_study_area_map.R`
- Hydrography: `analysis/hydrography/analysis_pie_temp_sal_sonde.R`
- Freshwater discharge: `analysis/discharge/analysis_parker_discharge_usgs.R`
- Burrow density: `analysis/burrow/burrow_density_analysis.R`
- Food-web trends: `analysis/plankton/fig_plankton_trends_nyt_with_fiddler.R`
- Optional mud fiddler MixSIAR rerun: `analysis/plankton/PIE_Mixing_Model/fiddler_crabs/mixsiar_fiddler_crabs.R`

The shared figure theme is provided in `analysis/common/theme_nyt.R`.

This package was synchronized on **2026-03-24** to the current submission-ready text and the canonical 20-crab fiddler MixSIAR rerun.

Authoritative fiddler analysis location:

- `analysis/plankton/PIE_Mixing_Model/fiddler_crabs/`

Archived or exploratory material is retained for provenance but should not be cited as the active submission analysis unless explicitly labeled otherwise.
