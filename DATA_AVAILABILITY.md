# Data Availability

The source inputs and derived outputs required to reproduce the analyses in this submission package are included in this repository.

Included inputs:

- Hydrography inputs: `analysis/hydrography/pie_temp_sal_sonde.csv`, `analysis/hydrography/High Tide Values.csv`
- Parker River discharge input: `analysis/discharge/parker_discharge_daily_selected_gauge.csv`
- Burrow survey inputs: `analysis/burrow/burrow_density.csv`, `analysis/burrow/PIE Fiddler Surveys_Master_V12.xlsx`
- Food-web inputs and MixSIAR summaries: files under `analysis/plankton/`

Derived outputs are written to:

- `results/`
- `figures/`
- `source_data/`

Submission and deposit notes:

- The active mud fiddler crab source-support analysis is the 20-individual two-isotope MixSIAR rerun in `analysis/plankton/PIE_Mixing_Model/fiddler_crabs/`.
- Archived non-canonical analysis branches are retained under `archive_noncanonical_20260324/` for transparency but are not part of the active submission workflow.
- A synchronized plain-text manuscript source aligned to these outputs is provided as `manuscript/NCC_Fiddler_Niche_submission_ready_2026-03-24.txt`.

The long-term stable isotope food-web data set cited in the manuscript remains attributed to the PIE LTER Environmental Data Initiative record referenced in the manuscript bibliography.
