# Source Data

This folder contains figure-level numerical source data prepared for submission support.

The active mud fiddler values used for Figure 3 are aligned to the canonical 20-crab MixSIAR rerun from `2023` and `2025`.

Files:

- `Figure1_hydrography_anomalies.csv`
  - Seasonal anomaly observations underlying the hydrography figure
- `Figure1_hydrography_trends.csv`
  - Regional hydrography trend summary table
- `Supplementary_Figure1_discharge_monthly_anomalies.csv`
  - Monthly Parker River discharge anomalies
- `Supplementary_Figure1_discharge_trends.csv`
  - Discharge trend summary table
- `Supplementary_Figure1_discharge_prepost_tests.csv`
  - Pre/post-2014 discharge comparison table
- `Figure2_burrow_annual_summary.csv`
  - Annual across-creek burrow density summary
- `Figure2_burrow_occupancy_summary.csv`
  - Annual transect occupancy summary
- `Figure2_burrow_trend_tests.csv`
  - Burrow trend statistics
- `Supplementary_Table_1_burrow_trends.csv`
  - Burrow trend results reported as Supplementary Table 1
- `Figure3_plankton_region_year_summary.csv`
  - Regional yearly marine-plankton summary
- `Figure3_plankton_species_year_summary.csv`
  - Species yearly marine-plankton summary
- `Figure3_plankton_region_trends.csv`
  - Regional plankton trend tests
- `Figure3_plankton_species_trends.csv`
  - Species plankton trend tests
- `Figure3_fiddler_mixsiar_summary.csv`
  - Mud fiddler MixSIAR source summary used for the green reference band
